# Changelog

All notable changes to the Audio Transcription Service will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- **🗣️ Full Speaker Attribution**: Complete speaker diarization using pyannote.audio
- **🎯 Enhanced Model Strategy**: Medium model default with automatic small model fallback
- **🏷️ Speaker-Labeled Output**: Both transcript and VTT captions include speaker identification
- **📊 Speaker Analytics**: Speaker count and timing metadata in diagnostics
- **⚡ Intelligent Degradation**: Graceful fallback when diarization models fail to load
- **🐳 Akash Network Support**: Complete deployment solution for decentralized cloud
- **📦 Pre-downloaded Models**: Container images include Whisper models for instant startup
- **💾 Model Cache Management**: Configurable model storage and caching strategies
- **📋 Model Documentation**: Comprehensive guide to Whisper model sources and optimization

### Changed
- **Default Whisper Model**: Changed from `small` to `medium` for better accuracy
- **Speaker Diarization**: Now enabled by default in web interface
- **Output Format**: Transcripts include `[Speaker N]` labels, VTT includes `<v Speaker N>` tags
- **Configuration**: Added `ENABLE_DIARIZATION`, `MAX_SPEAKERS`, `HUGGINGFACE_TOKEN` environment variables

### Planned
- User authentication with OAuth (GitHub/Google)
- Paid subscription plans with Stripe integration
- API key authentication for machine-to-machine access
- Webhook notifications for job completion
- Batch file upload functionality
- Advanced audio processing features (noise reduction, speaker identification)
- Multi-language UI support
- Real-time transcription via WebSocket
- Audio file format conversion endpoint
- Advanced admin dashboard with analytics

## [1.0.0] - 2024-12-19

### Added

#### Core Features
- **CPU-only audio transcription** using faster-whisper and CTranslate2
- **Complete audio processing pipeline**: transcription, VTT captions, summarization, topic extraction
- **Multi-format audio support**: MP3, WAV, FLAC, AAC, OGG, WebM, MP4
- **Text processing**: TextRank summarization and KeyBERT topic extraction
- **Free tier with strict limits**: 10 minutes/day, 15 min max file, 50MB size limit

#### API Endpoints
- `POST /api/v1/transcribe` - Upload and transcribe audio files
- `GET /api/v1/jobs/{job_id}` - Check job status and download results
- `GET /api/v1/usage` - Get usage statistics and remaining quota
- `GET /api/v1/admin/overview` - Basic admin dashboard
- `GET /healthz` - Health check endpoint
- `GET /metrics` - Prometheus metrics endpoint

#### Security & Rate Limiting
- **Device fingerprinting** with signed HMAC cookies (no accounts required)
- **IP-based tracking** with optional User-Agent hashing
- **Token bucket rate limiting** (15 burst, 1 token/minute refill)
- **Concurrent job limits** (1 active job per identity)
- **Daily usage quotas** (10 minutes, 10 files per day)
- **IP blocklist** for abuse prevention
- **File validation** with MIME type and magic byte checking

#### Storage & Infrastructure
- **Pluggable storage backend** (local files for dev, Cloudflare R2/S3 for production)
- **Signed URLs** for secure file downloads with expiration
- **Automatic file cleanup** (7-day retention policy)
- **Async job processing** with Celery and Redis
- **PostgreSQL database** with SQLAlchemy and Alembic migrations

#### Observability
- **Prometheus metrics** for monitoring and alerting
- **Structured JSON logging** with correlation IDs
- **OpenTelemetry tracing** support (optional)
- **Health checks** for all services
- **Admin dashboard** with usage statistics and top IP tracking

#### Deployment & Development
- **Docker Compose** setup for easy local development
- **Traefik reverse proxy** with automatic routing
- **Production-ready configuration** with environment variables
- **Comprehensive test suite** with pytest and coverage reporting
- **Load testing** with Locust framework
- **Code quality tools** (Black, Ruff, MyPy)

#### Web Interface
- **Simple HTML landing page** with drag-drop file upload
- **Real-time job status** updates with JavaScript polling
- **Usage quota display** showing remaining daily minutes
- **Download links** for all output files (transcript, captions, summary, topics)
- **Responsive design** that works on mobile and desktop

### Technical Details

#### Architecture
- **FastAPI** web framework with async/await support
- **Celery** distributed task queue with Redis broker
- **PostgreSQL** database with connection pooling
- **faster-whisper** for CPU-optimized speech recognition
- **ffmpeg** for audio format conversion and normalization

#### Performance
- **CPU-optimized processing** with int8 quantization
- **Audio normalization** to 16kHz mono for consistency
- **Efficient queue management** with priority-based processing
- **Connection pooling** for database and Redis
- **Horizontal scaling** support for multiple workers

#### Security
- **No user accounts** required for frictionless onboarding
- **HMAC-signed cookies** for device identification
- **Input validation** for all file uploads and API requests
- **Rate limiting** to prevent abuse and ensure fair usage
- **Secure file handling** with virus scanning hooks

#### Monitoring
- **Request/response metrics** with status code tracking
- **Job processing metrics** with queue wait times
- **Usage tracking** with daily/weekly aggregation
- **Error rate monitoring** with detailed error categorization
- **Performance metrics** with P95 latency tracking

### Configuration

#### Environment Variables
- Database: `DATABASE_URL`, connection pooling settings
- Redis: `REDIS_URL`, connection settings
- Storage: `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`
- Security: `COOKIE_SIGNING_KEY`, `PUBLIC_BASE_URL`
- Processing: `WHISPER_MODEL`, `MAX_DURATION_MIN`, `DAILY_CAP_MIN`
- Observability: `LOG_LEVEL`, `PROMETHEUS_ENABLE`, `TRACING_ENABLED`

#### Docker Services
- `api`: FastAPI application server
- `worker`: Celery worker for audio processing
- `postgres`: PostgreSQL database
- `redis`: Redis for queue and caching
- `traefik`: Reverse proxy and load balancer

### Testing
- **Unit tests** for all core functionality
- **Integration tests** for API endpoints
- **Load tests** with Locust for performance validation
- **Security tests** for rate limiting and input validation
- **Mock services** for external dependencies

### Documentation
- **Comprehensive README** with setup and usage instructions
- **API documentation** with OpenAPI/Swagger spec
- **Development guide** with local setup instructions
- **Deployment guide** for production environments
- **Troubleshooting guide** for common issues

### Known Limitations
- **CPU-only processing** (no GPU acceleration)
- **Free tier only** (paid plans not yet implemented)
- **No user accounts** (anonymous usage tracking)
- **Basic admin interface** (full dashboard planned)
- **Limited audio formats** (common formats supported)

### Dependencies

- faster-whisper 0.10.0
- FastAPI 0.104.1
- Celery 5.3.4
- SQLAlchemy 2.0.23
- PostgreSQL 15+
