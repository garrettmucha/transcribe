# 🚀 Akash Network Deployment Guide

Deploy the Audio Transcription Service on Akash Network - the decentralized cloud computing marketplace.

## 🏗️ Why Akash?

- **💰 Cost-effective**: Up to 85% cheaper than traditional cloud providers
- **🌍 Decentralized**: No single point of failure
- **🔒 Censorship-resistant**: Deploy anywhere in the world
- **⚡ Fast deployment**: From container to running service in minutes
- **🎯 Perfect for AI/ML**: GPU and CPU resources available

## 📋 Prerequisites

### 1. Install Akash CLI

```bash
# macOS
brew install akash-network/tap/akash

# Linux
curl -sSfL https://raw.githubusercontent.com/akash-network/node/master/install.sh | sh

# Windows (WSL)
curl -sSfL https://raw.githubusercontent.com/akash-network/node/master/install.sh | sh
```

### 2. Create Akash Wallet

```bash
# Create new wallet
akash keys add default

# Or import existing wallet
akash keys add default --recover
```

### 3. Fund Your Wallet

You need AKT tokens to deploy on Akash:

- **Minimum**: 5 AKT for deployment
- **Recommended**: 10-20 AKT for ongoing operation
- **Get AKT**: Buy on exchanges like Osmosis, Kraken, or Gate.io

### 4. Setup Container Registry

The service needs container images. Options:

**GitHub Container Registry (Free)**:
```bash
# Login to GitHub Container Registry
echo $GITHUB_TOKEN | docker login ghcr.io -u $GITHUB_USERNAME --password-stdin
```

**Docker Hub**:
```bash
docker login
```

## 🔧 Build & Deploy Process

### Step 1: Build Container Images

```bash
# Clone the repository
git clone <repository-url>
cd transcribe-service

# Build and push images (includes pre-downloading Whisper models)
# This step downloads ~769MB of models during build
./scripts/build-for-akash.sh --username your-github-username

# Or with custom registry
./scripts/build-for-akash.sh --registry docker.io --username your-dockerhub-username
```

**📝 Note**: The build process pre-downloads Whisper models (small + medium) to avoid startup delays. This makes the container image larger (~1.2GB) but ensures instant startup.

### Step 2: Configure Deployment

Edit the generated `akash/deploy.yaml`:

```yaml
# Update these environment variables:
env:
  - S3_ENDPOINT=https://your-account.r2.cloudflarestorage.com
  - S3_BUCKET=your-bucket-name
  - S3_ACCESS_KEY=your-access-key
  - S3_SECRET_KEY=your-secret-key
  - PUBLIC_BASE_URL=https://your-domain.com  # Will be provided after deployment
  - COOKIE_SIGNING_KEY=your-random-secret-key-32-chars-long
```

### Step 3: Deploy to Akash

```bash
# Deploy with our helper script
./scripts/deploy-to-akash.sh

# Or manually
akash tx deployment create akash/deploy.yaml --from default --chain-id akashnet-2
```

### Step 4: Monitor Deployment

```bash
# Check deployment status
akash query deployment list --owner $(akash keys show default -a)

# Check provider bids
akash query market bid list --owner $(akash keys show default -a) --dseq YOUR_DSEQ

# Check service status
akash provider lease-status --dseq YOUR_DSEQ --provider PROVIDER_ADDRESS --from default
```

## 🎯 Deployment Profiles

We provide different deployment configurations:

### Small Profile (Budget-friendly)
- **Resources**: 2 CPU, 4GB RAM
- **Model**: Whisper Small
- **Diarization**: Disabled
- **Cost**: ~$10-20/month

```bash
./scripts/deploy-to-akash.sh --deployment-file akash/deploy-small.yaml
```

### Standard Profile (Recommended)
- **Resources**: 6 CPU, 14GB RAM  
- **Model**: Whisper Medium
- **Diarization**: Enabled
- **Cost**: ~$30-50/month

```bash
./scripts/deploy-to-akash.sh --deployment-file akash/deploy.yaml
```

### High-Performance Profile
- **Resources**: 8 CPU, 20GB RAM
- **Model**: Whisper Large
- **Diarization**: Enabled
- **Cost**: ~$60-100/month

## 🔍 Service Configuration

### Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `WHISPER_MODEL` | Model size: small, medium, large | medium |
| `ENABLE_DIARIZATION` | Speaker identification | true |
| `MAX_DURATION_MIN` | Max audio length | 15 |
| `DAILY_CAP_MIN` | Daily processing limit | 10 |
| `MAX_SPEAKERS` | Max speakers to detect | 10 |

### Storage Configuration

**Cloudflare R2** (Recommended):
```yaml
env:
  - S3_ENDPOINT=https://your-account.r2.cloudflarestorage.com
  - S3_REGION=auto
  - S3_BUCKET=transcribe-storage
  - S3_ACCESS_KEY=your-r2-access-key
  - S3_SECRET_KEY=your-r2-secret-key
```

**AWS S3**:
```yaml
env:
  - S3_ENDPOINT=https://s3.amazonaws.com
  - S3_REGION=us-east-1
  - S3_BUCKET=your-s3-bucket
  - S3_ACCESS_KEY=your-aws-access-key
  - S3_SECRET_KEY=your-aws-secret-key
```

## 🛠️ Management Commands

### Update Deployment

```bash
# Update deployment with new configuration
akash tx deployment update akash/deploy.yaml --dseq YOUR_DSEQ --from default

# Send updated manifest
akash provider send-manifest akash/deploy.yaml --dseq YOUR_DSEQ --provider PROVIDER_ADDRESS --from default
```

### Scale Services

```bash
# Scale worker to 2 instances
# Edit deploy.yaml:
deployment:
  worker:
    dcloud:
      profile: worker
      count: 2  # Change from 1 to 2

# Apply update
akash tx deployment update akash/deploy.yaml --dseq YOUR_DSEQ --from default
```

### Monitor Resources

```bash
# Check resource usage
akash provider lease-status --dseq YOUR_DSEQ --provider PROVIDER_ADDRESS --from default

# View logs
akash provider service-logs --dseq YOUR_DSEQ --provider PROVIDER_ADDRESS --service api --from default
```

### Close Deployment

```bash
# Stop and close deployment
akash tx deployment close --dseq YOUR_DSEQ --from default
```

## 🔧 Troubleshooting

### Common Issues

**1. Deployment Stuck in "Pending"**
```bash
# Check if you have enough AKT balance
akash query bank balances $(akash keys show default -a)

# Check for bids
akash query market bid list --owner $(akash keys show default -a) --dseq YOUR_DSEQ
```

**2. No Bids Received**
- Lower resource requirements in deploy.yaml
- Increase pricing amounts
- Try different data centers

**3. Service Not Accessible**
```bash
# Check service status
akash provider lease-status --dseq YOUR_DSEQ --provider PROVIDER_ADDRESS --from default

# Check service logs
akash provider service-logs --dseq YOUR_DSEQ --provider PROVIDER_ADDRESS --service api --from default
```

**4. Out of Memory Errors**
- Reduce `WHISPER_MODEL` to `small`
- Disable diarization: `ENABLE_DIARIZATION=false`
- Increase memory allocation in profiles

### Debug Commands

```bash
# Check deployment details

akash provider status --provider PROVIDER_ADDRESS

# Check service events
akash provider service-logs --dseq YOUR_DSEQ --provider PROVIDER_ADDRESS --service api --tail 100 --from default
```

## 💰 Cost Optimization

### Reduce Costs

1. **Use Small Profile**: ~50% cost reduction
   ```bash
   ./scripts/deploy-to-akash.sh --deployment-file akash/deploy-small.yaml
   ```

2. **Disable Diarization**: ~20% memory/cost reduction
   ```yaml
   env:
     - ENABLE_DIARIZATION=false
   ```

3. **Lower Pricing**: Bid less AKT per resource
   ```yaml
   pricing:
     api:
       denom: uakt
       amount: 500  # Lower from 1000
   ```

4. **Reduce Processing Limits**:
   ```yaml
   env:
     - MAX_DURATION_MIN=10    # Down from 15
     - DAILY_CAP_MIN=5        # Down from 10
   ```

### Monitor Spending

```bash
# Check current spending
akash query deployment list --owner $(akash keys show default -a)

# Calculate monthly cost (approximate)
# Amount × 720 hours = monthly cost in uAKT
# Convert: uAKT ÷ 1,000,000 × AKT_price = USD
```
